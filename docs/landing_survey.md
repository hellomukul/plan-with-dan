# Home page survey (simulated, Oct 24, 2026)

Five AI agents, each playing a different visitor, reviewed screenshots and copy of the public home page. They also reviewed the team's proposed new order (builder in the hero, then the Ask Dan bar, programs, features, then FAQ). Each one answered a 10-question survey.

**This is simulated feedback, not a substitute for the classmate pilot.**

| Persona | Program | Hero pick (A builder / B calendar / C pick-and-see) | Would sign up |
|---|---|---|---|
| Priya | First-year MBA, mostly on her phone, anxious about bidding | A > C > B | maybe |
| Raj | EMBA, healthcare executive, weekends only | A > C > B (needs Fri/Sat) | maybe |

| Tomás | MAM, power user | A > C > B | maybe |

## What all five agreed on (and what changed)

| Finding | Votes | Change made |
|---|---|---|
| The fake "Good afternoon, Alex" card looks like someone else's life | 5/5 | Removed. The live week builder is the hero. |
| "Chief of staff for life at Yale SOM" is vague; say the job | 5/5 | The headline is now *Plan your SOM term. Clash-free, rule-checked, on time.* "Your chief of staff at Yale SOM" stays as the eyebrow, so the positioning is kept. |
| The AI pipeline ("Retriever, Curator agent, Critic agent") is jargon | 5/5 | Cut. It's now one FAQ answer: "AI suggests, software checks." |
| Put "not official" and "what's stored" near the top | 5/5 | A trust line under the buttons: *Free, no card · Independent student project, not official Yale · Never registers you · Nothing stored until you sign up.* |
| The builder must prefill; an empty grid "freezes" people | 4/5 | Program, year and cohort prefill what SOM schedules: fall core by cohort, MAM and MMS required courses, EMBA core. Notes say what can't be prefilled and why. |
| Move the FAQ above the features ("trust before features") | 4/5 | **The flow changed.** "Straight answers" now comes before "What a free account adds". |
| The programs section should follow my program | 2/5 | The program guide is synced with the builder's program. |
| "Coming up" shows MBA dates to EMBA students | 2/5 | EMBA and MMS-PEM get a link to their own calendar instead. |
| Admits need an example week with no cohort | 1/5 (Ella) | Added an "Admitted" option: a real Fall 2026 first-year week, clearly labelled "Example". |
| Units against my program's minimum; an .ics file without an account; data freshness | 1/5 (Tomás) | Added a unit counter ("14 units of 18 min"), a "Calendar file" download, and "Course data … as of Oct 24". |

| Example questions for the Ask Dan bar | 2/5 | Three chips, one of them about the visitor's program. |
| Program chips wrap into a wall on phones | 4/5 | They're now one row that scrolls sideways. |

## Asked for, but not done (and why)

- **A Fri/Sat EMBA grid (Raj):** SOM's public feed has no meeting times for 49 of its 50 EMBA sections. EMBA courses show as a list with a "no published time" note instead of a misleading grid.
- **Past auction prices and course reviews (Priya, Tomás):** SOM doesn't publish clearing prices, and reviews would need real student data. Bid coach already says so.
- **Yale SSO (Tomás):** this needs Yale IT approval, which an independent project can't get.
- **Chinese-language help (Lin):** out of scope for now. The plain-English rewrites address the main barrier.
- **Testimonials and user counts:** these wait for the real pilot; nothing invented.

## Final order

3. Ask Dan bar
4. Programs and Coming up
5. **Straight answers (moved up)**
6. What a free account adds
7. Footer
